# Changelog

按时间**正序**排列（不是常见的倒序），因为这份文档的价值在演进过程本身：每一版都是被一个具体事实推翻后重写的，倒序会把因果链切断。

每条修订标注类型，共五类：

- `事实错误` — 写错了用户的实际状况
- `规则矛盾` — 两条规则互相打架，模型会随机选一条执行
- `漏掉的情况` — 真实存在的约束没被写进去
- `判断不稳定` — 同一问题两次回答不一致，说明缺判据
- `表达不清` — 规则对，但模型会理解偏

30 条编号在正文各章的修订表里可对照（`## 零、设计说明`）。

---

## v1.0 — 2026-11

**触发**：用户提供一份 17 模块的提示词生成器模板，要求改造成长期使用的分身。

**改动**
- 从"生成器"（吃需求吐提示词）改为"分身系统提示词"（常驻角色、直接干活）
- 17 模块平铺 → 7 层架构（身份 / 认知 / 执行 / 输出 / 资产 / 运行 / 校验）
- 新增「业务档案」「资源与约束」：把公司、预算、人力写死，让模型自动过滤掉需要团队的方案
- 新增「决策输出契约」：4 种输出模式（速答 / 方案 / 诊断 / 复盘），每次输出必须给结论 + 动作 + 验收指标
- 新增「追问协议」「反幻觉条款」「版本迭代」
- 16 项工作从平铺列表重编为 8 个工作域，W1–W16 编号保留，可点单

**这一版的判断**：模板的问题是"填满但不会思考"。分层的意义不是好看，是让第 7 层（校验）能拦住第 3 层（执行）的输出。

## v2.0 — 2026-11

**触发**：填入真实业务档案 + 提供对标对象（同城同行，200 人规模）。

**改动**

| # | 类型 | 改动 |
|---|---|---|
| 7 | 漏掉的情况 | 新增「竞争定位」+「对标分析」：拆解对标的商业模式（双轨：零服务费含在单价里 / 5% 明佣）、内容策略、公开话术 |
| 8 | 判断不稳定 | 重写「信任工程」，新增差价模式的信任解法——市场已被教育过"低价或免费 = 暗中加价"，不处理这个怀疑，所有流量都漏 |
| 9 | 事实错误 | 90 天路线图重写为零基础版（原版假设有站点、有 GSC、有询盘） |
| 10 | 规则矛盾 | 新增明佣 / 差价双轨设计（**v2.1 被推翻**） |
| 11 | 表达不清 | 关键词库按"品类集群 + 区域"重排，不做全品类大词 |

**这一版的判断**：200 人对 1 个人，正面打必输。必须找它**结构上改不了**的弱点，不是找它做得不好的地方。

## v2.1 — 2026-11

**触发**：外部审查提出 15 条意见。

**15 条逐条处理**

| # | 类型 | 改法 |
|---|---|---|
| 1 | 规则矛盾 | 删"付费只做加速器"，改为精确搜索广告是已确认渠道（时点后续两次后移） |
| 2 | 规则矛盾 | **删掉"透明采购代理"（公开工厂名 / 加价比例 / 服务费行）**，改为"过程透明、价格一口价" |
| 3 | 规则矛盾 | **删除明佣 / Retainer 双轨与大单自动切换**，回归打包价单一模型 |
| 4 | 漏掉的情况 | 付款条件改为 70% 见提单副本 |
| 5 | 漏掉的情况 | 市场补回拉美：美国 > 欧洲 > 拉美 > 中东 > 东南亚 |
| 6 | 事实错误 | 基地改为义乌；删除"避开义乌小商品"整条建议 |
| 7 | 事实错误 | 改为一人公司、独立站 0 成交、暂不做阿里国际站 |
| 8 | 漏掉的情况 | 新增「运营红线」模块（无进出口权 / 不垫资 / 英文须审改 / 沟通依赖视频+翻译） |
| 9 | 判断不稳定 | 删除"做过 10 年、见过足够多案例"的经验背书，改为"不给经验背书，只给可验证判断" |
| 10 | 规则矛盾 | 删除所有未验证百分比（8–18% / 18%），改为占位符 + 必须填 |
| 11 | 判断不稳定 | 风险转移加"已批准清单"闸门，清单外不得自创退款 / 包赔 / 价格匹配 |
| 12 | 规则矛盾 | 英文素材从"可直接上线"降级为"待审改草稿"，必须标 `[DRAFT]` |
| 13 | 漏掉的情况 | 第 6 周的"案例页"改为"流程页"——0 成交时不得虚构案例 |
| 14 | 规则矛盾 | 报价单改动从"必做动作"改为"建议 + 需拍板"，与"不负责定价"边界对齐 |
| 15 | 表达不清 | 新增文档分层表，明确"系统提示词区"（一至七章）与"附录区" |

**这一版被推翻的核心建议（都在正文里留了记录，没有抹掉）**

- ① 要求公开加价 → 作废。用户是打包价模型，公开加价等于让他改商业模式。替代：**透明的是过程，不是价格。**
- ② 要求避开义乌打外地产业带 → 作废。用户就在义乌，这等于让他放弃唯一的地利。替代：**义乌是基地，不是限制。**
- ③ 经验背书 → 作废。一个自称十年经验的角色，会被诱导编造"行业平均 CPQL 是 $80"这类假基准，而用户无法分辨。**放弃资历背书 = 放弃编造数据的许可证。**

## v2.2 — 2026-11

**触发**：用户确认 8 项事实，其中一条改变了整个策略地基——**0 基础转型，从未成交过任何一单**（不是"独立站 0 成交"，是整体 0 成交）。

| # | 类型 | 触发事实 | 改动 |
|---|---|---|---|
| 16 | 事实错误 | 完全没成交过 | 新增「冷启动路径」：5 条不依赖流量的第 1 单路径，优先级高于 SEO / 广告 |
| 17 | 漏掉的情况 | 无进出口权但可立即办理，不做买单出口 | 红线 1 改为两阶段（办证前 / 办证后两套写法），切换需用户明确告知 |
| 18 | 漏掉的情况 | 无可拍摄的工厂 / 仓库 / 档口，但可以去开发 | "过程可见"加前置条件：先建供应商池才能拍；W1–W2 增加供应商开发动作 |
| 19 | 事实错误 | 没有真实见过的踩坑案例 | 删除首条询盘模板里的编造段落，改为「结构性事实」写法；新增禁止"我见过 / 上个客户"句式的硬规则 |
| 20 | 规则矛盾 | 除睡眠外都能回复 | 回复承诺改为 `within 2 hours, 09:00–24:00 GMT+8`，并加"写下去就要做到"的提醒 |

**连带改动**
- 约束闸门 6 → 7（新增「交付就绪闸」）
- 90 天路线图重排为双轨：主轨补交付，副轨补流量
- 第一个月 3 件事全部换掉
- 自检新增 2 项：编造检验、冷启动检验

**这一版的判断**：0 成交 → 无社会证明 → 转化低 → 仍 0 成交，是死循环。破法不是"更多流量"，是**用手动方式（不依赖流量）先拿到第 1 单，用它换第一个证据**。

## v2.3 — 2026-11

**触发**：三项确认——六项交付能力全部"不会，还在学习"、客单 $1,000/款起、品牌名无想法。

| # | 类型 | 改动 |
|---|---|---|
| 21 | 事实错误 | 新增「交付能力与补课路径」：六项逐条拆"能不能承诺 / 补多久 / 怎么验收"，并分三级——A 流程知识（1–3 周）/ B 现场判断（4–8 周）/ C 人际技能（3–6 个月） |
| 22 | 规则矛盾 | 新增「服务产品化」L0–L3 四层，**现在只卖 L0–L1**；定位收紧；第一单定义从 $1,000–5,000 降为 $200–800 |
| 23 | 判断不稳定 | 广告数学重算：$1,000 客单毛利 $150–500 撑不起 CPQL $100–600 → 投放推至 W9、预算压到 ¥1,000–1,500 |
| 24 | 规则矛盾 | 报价单模板标为"L2 专用，60 天内别用"；新增 L0/L1 报价单 |
| 25 | 表达不清 | 90 天路线图第三次重排：主轨改为补课，W4 上线 L0 服务页，W9 才投广告 |
| 26 | 漏掉的情况 | 品牌名 10 候选 + 3 条命名原则 + "看着好但别用"清单 + 域名/商标自查顺序 |

**连带改动**
- 约束闸门 7 → 8（新增「能力闸」）
- 自检 11 项（新增「能力检验」，标注为最重要的一项——它是唯一会让用户赔钱和赔信用的）
- 定位从"透明采购代理"改为 **"你在义乌的眼睛和手"**，并给 0 供应商期间可用的过渡主标题

**这一版的判断**：「我全不会」不等于「我做不了」。六项里三项是纯流程活（查表 + 套模板），1–3 周能学会。但**不会的期间绝不能对外承诺结果**——可以承诺"我去跑、我去拍、我把报价摆在你面前"，不能承诺"我保证质量、我保证清关"。

## v2.4 — 2026-11

**触发**：4 项决策拍板——进出口权本月底下来、品类锁定 4 个、L0 定价 ¥500 起、建站用 WordPress + 模板。

其中两条不是"补充信息"，是**新的约束**，必须点出来。

| # | 类型 | 改动 |
|---|---|---|
| 27 | 规则矛盾 | 4 个品类 → 3 个集群页（Headwear + Hair Accessories 合并为 Fashion Accessories，因为义乌同一个产业带）；主攻顺序改为 P0 Fashion Accessories → P1 Home & Kitchen → P2 Pet Supplies；理由是"按成交速度排，不按客单排" |
| 28 | 漏掉的情况 | 新增「L0 范围边界表」：价格不动，用"半天 + 1 品类 + 走访 5–8 家 + 20 图 3 视频 + 3 个工作日"划范围，超出 ¥1,000/天。并补全 L0 毛利与 CAC 数学 → **L0 永远不投广告** |
| 29 | 事实错误 | 进出口权到手 ≠ 能做采购单。L2 拆成四道门（证 / FOB / 单证 / 3 家供应商），最早 2027-01 中才开 |
| 30 | 漏掉的情况 | WordPress 5 条避坑（插件只装 5 个 / 删演示内容 / 图片压 200KB / 主机别贪便宜 / 固定链接用文章名） |

**这一版被推翻的判断**

主攻品类从 Home & Kitchen 改成 Fashion Accessories。理由不是"发饰更好卖"，是零成交阶段**最缺的是快成交，不是高客单**：

- 发饰 / 帽类客户决策 3–10 天，家居 2–6 周
- 发饰区一天能跑 20 家，家居区 5 家——供应商密度 = 比价速度 = 唯一能赢大同行的能力
- 小件可手持、可在档口直接拍；家居大件要进仓库、要布光

**这一版的判断**：¥500 会筛出期望值最高的客户。解法不是涨价，是**把"不包含"写在前面**——不讲理的客户不会因为价格高就走，只会因为"你不肯多干"而走，那正是要的。
